# Salon Demo — suke Web制作 ポートフォリオ

美容室・ネイルサロン向けランディングページのデモサイトです。

## 技術スタック

- HTML5
- CSS（tokens.css — OKLCH デザイントークン）
- Tailwind CSS（CDN）
- Vanilla JavaScript
- Vercel（ホスティング）

## ブランチ運用

| ブランチ | 役割 |
|---|---|
| `main` | 本番（Vercel デプロイ） |
| `develop` | 開発統合 |
| `feature/xxx` | 機能単位の作業ブランチ |

## ローカルで確認

```bash
open index.html
```
